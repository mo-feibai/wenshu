# 示例接口文档

> 本文件为演示用的虚构内容，用于展示文枢文档库的元数据与渲染形态。

## 1. 接口说明

查询示例条目列表，支持按名称模糊匹配与分页。

## 2. 请求

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 否 | 名称模糊匹配 |
| `page` | int | 否 | 页码，默认 1 |
| `size` | int | 否 | 每页条数，默认 20 |

## 3. 响应

```json
{
  "code": 0,
  "data": {
    "total": 1,
    "items": [
      { "id": 1, "name": "示例条目" }
    ]
  }
}
```

## 4. 备注

- 表结构见关联的迁移脚本。
- 附件中包含一个本地测试页面。
