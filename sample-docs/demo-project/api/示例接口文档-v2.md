# 示例接口文档 v2

> 本文件为演示用的虚构内容，用于展示版本链与「与上一版改动」差异卡片。

## 本版变更

- 2. 请求：新增 `sort` 参数（`id`/`name`，默认 `id`）。
- 3. 响应：`items` 新增 `updated_at` 字段。

## 1. 接口说明

查询示例条目列表，支持按名称模糊匹配、排序与分页。

## 2. 请求

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `name` | string | 否 | 名称模糊匹配 |
| `sort` | string | 否 | 排序字段：`id` / `name`，默认 `id` |
| `page` | int | 否 | 页码，默认 1 |
| `size` | int | 否 | 每页条数，默认 20 |

## 3. 响应

```json
{
  "code": 0,
  "data": {
    "total": 1,
    "items": [
      { "id": 1, "name": "示例条目", "updated_at": "2026-09-05 10:00:00" }
    ]
  }
}
```
